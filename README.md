# Chill Pros Commercial Platform

Upload-ready Progressive Web App prototype for Chill Pros.

## Includes
- iPhone/iPad installable PWA
- Official Chill Pros logo branding
- Technician, office, sales, owner, and client portal login flow
- Time clock with GPS-ready structure
- Dispatch/new jobs
- GPS directions links
- Client directory
- Customer-specific equipment/asset files
- Quote and invoice screens
- Before/after photo placeholders
- Customer signature area
- QuickBooks Payments integration placeholder
- PM programs
- Parts rescue system

## Important
This is a front-end commercial-grade prototype shell. Before using with live customers, connect:
- Secure backend database
- Real employee authentication
- QuickBooks/Intuit OAuth
- QuickBooks Payments invoice/payment links
- Secure file upload storage
- Role-based permissions on the server

Never put bank account numbers directly into website code. Add Bank of America as the payout bank inside QuickBooks Payments.
