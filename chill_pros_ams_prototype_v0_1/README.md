# Chill Pros AMS Prototype v0.1

## Open immediately
Open `web_demo/index.html` in Chrome, Safari, or Edge. No installation is required.

## Flutter source
The `flutter_app` folder contains the mobile/web Flutter starter source.

After installing Flutter:

```bash
cd flutter_app
flutter create .
flutter pub get
flutter run -d chrome
```

## Included prototype functions
- Responsive Chill Pros operations dashboard
- Asset registry with search and equipment filters
- Asset detail records
- Add-asset workflow with automatic CP-SA numbering in the web demo
- QR scan simulation and manual asset lookup
- PM queue
- Work-order and reporting placeholders
- Mobile-responsive navigation
- Flutter starter implementation using SDK-native components
